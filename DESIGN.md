# LinkForge Design System

- **Mode**: Operate (precision SaaS workspace).
- **Palette**:
  - Light: `#f8fafc` canvas, `#ffffff` elevated surface, `#f1f5f9` sidebar/secondary layer, `#0f172a` ink, `#475569` muted ink, `#e2e8f0` hairline border.
  - Dark: `#09090b` canvas, `#111114` elevated surface, `#141418` sidebar/secondary layer, `#fafafa` ink, `#a1a1aa` muted ink, `#27272a` hairline border.
  - Accent: `#2563eb` (light) / `#3b82f6` (dark) reserved strictly for primary actions, active nav, and focus rings.
  - Semantic: `#16a34a` success, `#d97706` warning, `#dc2626` danger.
- **Typography**: `Inter` (`--font-sans`) + `JetBrains Mono` (`--font-mono`) with `tabular-nums` for metrics, slugs, and timestamps.
- **Craft rules**: No kickers/eyebrows, no gradient text, no nested cards, 150ms–200ms state transitions, crisp hairline borders.
